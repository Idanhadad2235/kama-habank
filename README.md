# כמה הבנק לוקח לי?

אתר שקורא את תעודת הזהות הבנקאית בתוך הדפדפן, משווה את העמלות והריביות לממוצעים של בנק ישראל, ומראה כמה אפשר לחסוך.

## פרטיות

הדוח נקרא בדפדפן בלבד. הוא לא נשלח לשום שרת ולא נשמר. נשלחות רק הודעות שגולשים כותבים בצ'אט.

## הקבצים

| קובץ | מה יש בו |
| --- | --- |
| `index.html`, `app.js` | העמוד: העלאה, בדיקת המספרים, תוצאות |
| `parser.js`, `extract.js` | קריאת הדוח מה-PDF |
| `analysis.js`, `data.js` | ההשוואה לממוצעים, החיסכון, ההודעות המוכנות, צירוף שני חשבונות |
| `benchmarks.js` | נתוני ההשוואה ומקורותיהם, מתעדכנים פעם בחודש |
| `chat.js`, `admin.js`, `backend.js` | הצ'אט ותיבת ההודעות (`#admin`) |
| `faq.js`, `pages.js` | שאלות ותשובות, תנאי שימוש, פרטיות ונגישות |
| `config.js` | הגדרות האתר החי: כתובת, תיבת ההודעות, ספירת כניסות |
| `backend/Code.gs` | תיבת ההודעות ב-Google Apps Script |

## בדיקות

```
node tests/analysis.test.mjs
node tests/backend.test.mjs
```

האתר משתמש ב-[PDF.js](https://mozilla.github.io/pdf.js/) של Mozilla, ברישיון Apache 2.0.
